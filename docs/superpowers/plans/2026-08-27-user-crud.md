# 用户 CRUD 全功能实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 接通用户管理全功能 — 后端 7 个 API stub → UserManager，前端列表/创建/编辑/删除 UI，TDD 测试 + E2E Playwright 测试。

**Architecture:** 后端 `routes/users.ts` 的 6 个 501 stub 接入 `@accessbase/identity` 的 `UserManager`，新增 PATCH status 端点。前端新增 `api/users.ts` 客户端 + ProTable 列表 + Modal 表单。统一 `tenantId = DEFAULT_TENANT`。User 实体使用 `isActive: boolean`（后端真实字段）。

**Tech Stack:** Fastify, Drizzle ORM, UserManager, React, Ant Design ProTable, Playwright

**Spec:** `packages/identity/src/managers/UserManager.ts`, `packages/identity/src/types.ts`, `packages/types/src/entities.ts`

## Global Constraints

- `tenantId`: 固定 `00000000-0000-0000-0000-000000000001`
- API 路径: `/api/v1/users/*`（含 `/v1/` 前缀）
- 返回格式: `{ success: true, data: ..., total?: number }`
- **User 实体无 `status` 字段** — 使用 `isActive: boolean`，前端映射为标签
- **User 实体无 `roles` 字段** — 不在列表/表单中展示
- **PATCH /users/:id/status** — 独立端点调用 `UserManager.changeStatus()`
- **DB 连接**: UserManager 实例在路由模块级复用
- 保持 Fastify schema 验证

```typescript
// apps/server/src/routes/users.ts
import type { FastifyInstance } from 'fastify';
import { UserManager } from '@accessbase/identity';

const DEFAULT_TENANT = '00000000-0000-0000-0000-000000000001';

export async function userRoutes(app: FastifyInstance) {
  app.addHook('preHandler', (app as any).authenticate);
  const userManager = new UserManager(); // Reuse instance

  // GET / — paginated list
  app.get('/', { schema: { /* querystring: page, pageSize, search, status, sortBy, sortOrder */ } },
    async (request) => {
      const { page = 1, pageSize = 20, search, status, sortBy, sortOrder } = request.query as Record<string, any>;
      const result = await userManager.findAll({ page, pageSize, search, status, sortBy, sortOrder }, DEFAULT_TENANT);
      return { success: true, data: result.data, total: result.total };
    });

  // GET /me — current user
  app.get('/me', async (request) => {
    const payload = request.user as { sub: string };
    const user = await userManager.findById(payload.sub, DEFAULT_TENANT);
    if (!user) throw new Error('User not found');
    return { success: true, data: { id: user.id, email: user.email, name: user.name, isActive: user.isActive } };
  });

  // GET /:id — by ID (404 if not found)
  // POST / — create (409 on duplicate email)
  // PUT /:id — update (404 if not found)
  // PATCH /:id/status — changeStatus (404 if not found)
  // DELETE /:id — delete (404 if not found)
  // (all use userManager with DEFAULT_TENANT, catch errors → appropriate HTTP status)
```
